# Churn Modelling Project

This project contains the Churn Modelling dataset and Python dependencies for an artificial neural network churn prediction project.

## Setup

Create and activate a virtual environment, then install dependencies:

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## Dataset

`Churn_Modelling.csv` contains the project dataset.
